01它是什么

World Monitor 是 GitHub 上的开源“全球实时态势”看板：新闻聚合、地缘冲突、基础设施、市场等几十个面板，另有科技、金融、能源等分站。完整版要自己用 Docker 跑一整套服务（数据库、缓存、抓取器和多个 API 密钥），所以我没有把整套搬到本站，而是用作者官方提供、允许外站嵌入的免费地图。

02急诊科的比喻

它像急诊的中央监护大屏：每张床的心电、血压、血氧汇在一块屏上，红了就先看哪一床。World Monitor 把“世界的生命体征”汇到一张图上。但大屏只负责提示，不负责诊断——报警之后，还得走到床旁核实。

03课上怎么用

信息素养

选一个地图上的事件，让学生分别找到原始来源（通讯社、官方地震台），比较 AI 摘要和原文差在哪。

医疗关联

地震、极端天气、冲突会直接带来创伤和批量伤员。可以用来讨论灾害医学和急诊资源预案。

AI 架构

它是“数据抓取 → 汇总 → AI 摘要 → 可视化”的完整示范，和课上讲的智能体、知识库思路一致。

开源学习

源码公开，可以读它的 ARCHITECTURE.md，看一个真实大项目怎么拆模块。

04要小心什么

  • 不是权威信源。事件位置和描述来自自动聚合，可能延迟、重复或误报，引用前回原始来源核对。
  • 地缘信息敏感。课上只做信息素养和灾害医学讨论，不做政治评论。
  • 国内访问可能不稳。地图加载不出来时，直接点“打开完整看板”。
  • 许可证是 AGPL-3.0。如果以后要改代码再自己部署对外服务，改过的源码也必须公开。
