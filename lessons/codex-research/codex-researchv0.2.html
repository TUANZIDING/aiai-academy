规则一个任务一个文件夹，用 AGENTS.md 写清规则

最重要的文件：AGENTS.md

它是你写给 Codex 的任务规则。Codex 进入文件夹就会照着它干活。

这是一个文献搜索任务。
研究主题：生成式 AI 对研究生科研自我效能的影响。
规则：
1. 不要凭模型记忆编造论文。
2. 所有推荐文献必须提供标题、作者、年份、来源、DOI 或可访问链接。
3. 先生成检索式，再执行检索，再整理结果。
4. 输出结果保存到 search-results/ 文件夹。
5. 不确定的信息请标记为“待核查”，不要写成确定结论。
这是一个问卷数据分析任务。
数据文件：data.csv
变量说明：variable-dictionary.md
规则：
1. 所有统计结果必须来自 data.csv。
2. 所有图表必须由 Python 或 R 代码生成，不要用图片生成模型直接画统计图。
3. 每一步分析都要保留代码。
4. 输出 data_quality_report.md、analysis_report.md、figures/ 和 scripts/analysis.py。
5. 如果变量不适合做某种统计分析，请先说明原因，不要硬做。

“帮我做科研。”

✓ 而是先让它进入上下文

先读文件夹和规则，复述目标、已有材料、缺失材料和下一步建议。

请先阅读当前文件夹和 AGENTS.md，告诉我你理解到的任务目标、已有材料、缺失材料，以及下一步你建议执行的操作。先不要直接生成最终结果。

要点这一步让 Codex 先进入任务上下文，而不是直接开始自由发挥。

第二步

Skill 不是提示词，而是成熟 SOP

同一个 Codex，配置了不同 Skill，能力会差很多。

一个好的 Skill 写清这六件事

1什么时候用
2需要什么输入
3按什么步骤执行
4能调用哪些脚本
5最后输出什么
6哪些事情不能做

不要因为一个 Skill 很火，就直接拿来写论文

例：K-Dense 的 Scientific Agent Skills 含 148 个科研 Skill，覆盖癌症基因组学、药物靶点结合、分子动力学、RNA velocity、地理空间、时间序列、科学数据库等，整体偏生物、化学、医学、组学和科学计算。

教育学、新闻传播、管理学、社会学或计算机写作方向，要看的是它的工作流是否适合你的研究任务，而不是热度。

请先不要执行任务。请阅读这个 Skill 的 SKILL.md，并用中文总结：
1. 这个 Skill 适合解决什么问题？
2. 它需要我提供哪些输入材料？
3. 它会调用哪些脚本、工具或外部服务？
4. 它最终会输出哪些文件或结果？
5. 它明确不适合做什么？
6. 结合我的研究任务，你认为这个 Skill 是否适配？如果不适配，需要改哪些规则？

不匹配怎么办

别硬用。让 Codex 基于它改一版适合自己的流程，或把实验室常用流程沉淀成自己的 Skill。

最适合写成 Skill 的例子

论文终稿检查：查数值、查图表编号、查参考文献、查统计符号、查格式、查基金号。以后终稿前直接调用即可。

场景一

论文搜索：先生成检索路径，再真实检索

✕ 最危险的问法

“请推荐 20 篇关于生成式 AI 和研究生科研能力的论文。”

模型可能凭记忆列出一批看起来很像真的文献，没有真实检索，也没有 DOI、PMID 或数据库链接。
✓ 正确路径

拆主题 → 生成检索式 → 用 Skill 或脚本真实检索 → 整理文献表

  1. 拆主题概念矩阵
  2. 检索式多组、各有角度
  3. 真实检索Skill / API
  4. 文献表去重、可核查

场景二

综述写作：AI 擅长阅读理解，但必须基于真实论文

综述本来就要大量阅读、归纳、比较、分类，这正是 AI 的强项。前提只有一个：必须基于真实论文。建议给 Codex 接入论文搜索 API，或使用已接入论文库的工具。

场景三

数据分析：让 Codex 写代码跑结果，不要让大模型直接画图

真正麻烦的是清洗变量、查缺失、跑统计、导表、画图、写报告。Codex 能写代码、运行、看报错、改代码，再把结果存下来。

底线

数据分析结果必须通过代码和真实数据生成，不能让大模型凭空生成统计图。

  3. 写代码并运行代码、表格、图全部可追溯

场景四

答辩 PPT：论文写好了，不要再手搓每一页

论文是长文本，PPT 是现场表达。从论文到 PPT，核心不是“换个格式”，而是重新组织答辩逻辑。

codex-ppt-skill 怎么工作

先规划大纲和视觉风格 → 生成样张确认 → 逐页生成幻灯片图片 → 组装成 .pptx，并生成 speech.md 写进每页备注。可处理文章、报告、论文、课程笔记、Markdown、PDF、Word。

npx -y skills@latest add ningzimu/codex-ppt-skill \
 --skill codex-ppt \
 --agent codex \
 --global
优点

整页图片式 PPT，视觉统一、速度快，适合快速把论文变成可讲的答辩稿。

局限

页面元素不一定能逐个编辑。要精修，就用可编辑 PPT 转换工具，或在 PowerPoint 里手动调整关键页。
