# AI 文献检索课

图文自学和 16:9 授课共用 `index.html`。命题是：搜不到，不等于不存在。

## 打开

在本目录启动静态服务：

```bash
python3 -m http.server 8080
```

浏览器访问 `http://127.0.0.1:8080/`。文件也可以直接双击打开。用 `file://` 时，复制按钮可能失败，页面会选中文字并提示手动复制。

授课：点「进入授课」。方向键翻页，`B` 黑屏，`F` 尝试全屏，`Esc` 先退出黑屏再退出授课。全屏被拒绝时仍留在普通窗口。分享某一页可在地址后加 `?view=teach#s-myth`。

打印用浏览器的打印功能，得到全部章节，不停留在当前一张幻灯片。

## 本包里有什么

`index.html`、`assets/css/course.css`、`assets/js/rules.js`、`assets/js/course.js` 和 `assets/images/` 里的原创 SVG。没有远程字体，没有统计脚本，没有在线检索。

## 本包里没有什么

没有原文全文，没有原帖截图，没有课堂照片。那些材料没有随本课公开。图注里的「教学整理」是本课绘制的示意图，不是数据库截图，也不是论文证据。案例卡片上的 DOI `10.0000/example.not.real` 是无效示例。

## 事实口径

官方数字核对日是 2026-11-08（北京时间）。价格、收录和限速可能变化，以页面上的官方链接为准。五个案例来自兔老师 @DrRabbitAI 的演示，原帖是 https://x.com/DrRabbitAI/status/2117952642593017862 。篇数、样本量、期刊分区、论文年份和专利申请人都没有在本课里独立复现。

不要把真实 API key 填进这些文件。模板只使用占位符 `OPENALEX_API_KEY`。
