# Lower-leg anatomy meshes (leg-anatomy-v0.4.glb / .json, js/anatomy-v0.4.js contour tables)

- Geometry: BodyParts3D, © The Database Center for Life Science licensed under CC Attribution-Share Alike 2.1 Japan.
- Via Z-Anatomy (https://github.com/LluisV/Z-Anatomy), CC BY-SA 4.0; converted model files and structure catalogue taken from the
  BodyVista build (https://github.com/FreedomIntelligence/BodyVista; BodyVista code is MIT © 2026 FreedomAI — no BodyVista code is reused here).
- Modifications: right leg cropped knee→ankle, Taubin smoothing, loop subdivision (bones), decimation where needed, baked muscle/tendon
  vertex colours and cylindrical UVs; skin envelope derived from the union of all structures + 4.5 mm. Scripts: tools/prep-leg-v0.3.py, tools/prep-anatomy-v0.3.py; v0.4 revision (anterior tibial vessels re-registered onto the interosseous membrane, anatomical skin) by tools/prep-leg-v0.4.py (kept in the courseware source, not published).
